# 2단계 구현 및 검증 기록

검증일: 2026-10-19, 한국 시간. 자동 커밋/스테이징/기존 파일 삭제는 수행하지 않았습니다.

## 환경과 실행

기존 `.venv`의 Python 3.12.15를 사용했습니다. PySide6 6.10.2는 유지하고
MediaPipe 1.1.1 및 해당 필수 의존성을 설치했습니다. cv2 모듈 중복을 피하도록
`opencv-python`을 같은 4.13.0.92의 `opencv-contrib-python`으로 대체했습니다.
NumPy 2.5.4는 유지했습니다. `uv pip check`로 23개 설치 패키지의 호환성을 확인했습니다.
모델은 [공식 Full float16 버전 1](../models/README.md)입니다.

```powershell
.\.venv\Scripts\python.exe -m app.main
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests/run_pose_smoke.py --video data/videos/20260707_154513.mp4
```

## 자동 테스트

총 **19개 통과**. 실제 MP4 디코딩을 사용하는 기존 플레이어 테스트 5개는 수정하지 않았습니다.
추가 14개는 합성 관절/가짜 검출기를 사용하여 다음 사항을 검증합니다.

- visibility/presence/화면 범위/비정상 수치 필터
- 33개 관절과 크롭 좌표·깊이의 원본 역변환, 중복 후보 제거
- 다인 클릭 선택, 겹치는 후보 선택 보류
- MediaPipe 출력 순서 변경 시 선수 연결 유지, 선택 프레임 기준 앞뒤 추적
- 누락·급격한 이동·경쟁 후보 등장 시 중단 및 자동 재연결 금지
- 원본 불변, 선택 선수 색상 차이, 신뢰도 부족 관절 표시 제한
- 두 가지 화면 비율의 클릭 좌표 역변환과 레터박스 클릭 무시
- 분석 중 Qt 타이머/프레임 이동 응답, 프레임 시간 및 슬라이더 연동
- 취소 후 부분 캐시 보존 및 재분석, 영상 재열기 시 이전 작업 결과 폐기
- 파일/모델 식별자 변경 시 캐시 무효화
- AI 오류 후 플레이어 유지, 모델 누락, VIDEO 시간 역행 거부

손상 영상/모델 누락/추론 실패 테스트의 오류 로그는 의도적으로 발생시킨 정상적인 검증 출력입니다.

72프레임 전체를 사람이 신원 정답과 대조한 것은 아닙니다.

초기 전체 화면 단독 추론에서는 복수 후보가 한 선수에 겹치는 경우가 있어
두 선수 구분 검증이 충분하지 않았습니다. 겹침 영역의 추가 추론과 원본 좌표
역변환/중복 제거를 구현한 후 최종 검증을 통과했습니다. 이로 인해 분석 시간과
모델 메모리 사용량이 증가했습니다. 오프스크린 실행에서는 Qt 한국어 글꼴이
없어 네모로 표시되었으므로 외관 검증에는 Windows 네이티브 화면을 사용했습니다.

## 제한 사항과 미검증 항목

- 최대 4명이며 먼 선수/가림/유사 자세/유사 복장/중복 검출을 완전히 해결하지 못합니다.
  영구 신원 추적 및 재식별은 제공하지 않으며, 혼동 위험 시 재선택해야 합니다.
- 모든 교차·가림 상황의 신원 오류 방지율, 전체 경기 길이의 메모리/장시간 안정성,
  나머지 사용자 영상 전체 분석, 다른 PC/코덱/디스플레이 배율은 검증하지 않았습니다.
- 프레임 번호와 플레이어의 FPS 시간축은 일치합니다. VFR 원본 PTS와의 정확한 동기화는
  검증하지 않았으며 현재 구현하지 않았습니다.
- 캐시는 메모리에만 저장합니다. 취소/오류 결과는 부분 데이터이며 완료 결과와 구분됩니다.
- 월드 좌표는 모델 추정값입니다. 크롭 영역별 월드 좌표의 정밀 정합/카메라 보정은 제공하지 않습니다.
- 표시 시 원본 비율/해상도를 기준으로 그리지만 골격의 해부학적 위치 오차는 모델에 의존합니다.
- 오디오, 관절 각도 평가, 스매시/클리어 분류, 코칭 점수/교정, 타격 순간 분석은 구현하지 않았습니다.

다음 단계에서는 촬영별 정답 라벨과 신원 평가 자료를 확보하고, VFR PTS,
긴 영상의 캐시 용량 제한/디스크 저장, 측정 신뢰도·단위·좌표계 검증을 먼저 고려해야 합니다.

