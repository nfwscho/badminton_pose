# 3단계 관절 측정·시간축 구현 및 검증 기록

검증일: 2026-10-19 (한국 시간). 기존 2단계 커밋 `2a714cf`에서 시작했으며
기존 테스트와 모델 파일은 보존했습니다. 자동 커밋/스테이징은 하지 않았습니다.

## 구현 범위

- NumPy 순수 계산 함수로 좌우 팔꿈치/무릎/어깨 영상 평면 내각, 몸통 화면 기울기,
  같은 쪽 어깨에 대한 손목 상대 높이를 계산합니다.
- 정규화 좌표를 원본 영상의 x×width, y×height로 바꾸므로 가로/세로 축척을 혼동하지 않습니다.
- 팔꿈치/무릎은 편 상태 180도, 어깨는 팔꿈치–어깨–골반 내각입니다.
  몸통 기울기는 골반 중심→어깨 중심과 화면 위쪽 수직축의 내각입니다.
- 손목 높이 = (어깨 Y − 손목 Y) / 어깨 중심과 골반 중심 사이 길이입니다.
  어깨보다 위에 있는 손목이 양수입니다. 각도는 0–180도이고 높이는 몸통 길이 단위입니다.
- 신뢰도 필터, 화면 범위, 영/미소 벡터 및 선택 선수의 추적 상태를 검증합니다.
  관절 부족/식별 실패 시 이전 값을 채우지 않습니다.
- 기존 관절 캐시만 사용하며 각도 계산/선수 재선택/구간 변경에 MediaPipe를 재실행하지 않습니다.
- `FrameMeasurement`에 프레임/실제 시간/선택 세션/연속 구간/추적 상태·중단 원인을 저장합니다.
  각 `MetricValue`의 raw/display/valid/reason을 분리합니다.
- 표시용 평활화는 같은 신원/유효 연속 구간 안의 인접 3프레임 원시값 평균입니다.
  중앙 프레임이 무효이면 평활화로 보충하지 않습니다. 현재 값/통계는 항상 raw 기준입니다.
- 독립 각도 토글, 접이식 QSplitter 패널, 항목별 그래프, 재생 위치선/마우스 탐색,
  확대/축소/초기화, A/B 구간과 비동기 CSV 저장을 추가했습니다.
- A와 B 프레임은 포함하며 길이는 B 프레임의 표시 종료까지입니다.
  미지정 시 선택 세션의 추적 가능한 첫~마지막 프레임이 통계 범위입니다.
  구간 A/B는 선수 재선택 시 유지하고 영상 변경 시 초기화합니다.
- 통계는 유효 표본 2개 이상일 때 최소/최대/변화폭을 제시합니다.
  변화폭은 최대−최소이며 실제 변화가 없을 때만 0입니다.

## 실제 시간과 기존 재생의 변경점

[PyAV의 PTS/time_base](https://pyav.org/docs/stable/api/time.html)를 사용하여 표시 순서의
프레임을 백그라운드에서 인덱싱합니다. 첫 표시 프레임의 시각을 0초로 정규화하며
원본 PTS 초도 보존합니다. 플레이어 시간/프레임별 재생 간격/그래프/CSV가 같은 시간축을 사용합니다.
인덱싱 중에는 기존 FPS 추정 재생을 유지하고 UI에 확인 중임을 표시합니다.

PTS 누락/역행에만 FPS 추정값을 사용하고 출처와 대체 프레임 수를 UI/로그/CSV에 명시합니다.
MediaPipe 입력은 실제 시간을 밀리초로 반올림하되 최소 1ms씩 증가시킵니다.
이 보정 입력은 `model_timestamp_ms`에 저장하며 실제 측정 시간을 덮어쓰지 않습니다.
시간축과 OpenCV 프레임 수 또는 영상 식별 정보가 다르면 분석을 보류합니다.

그래프는 [pyqtgraph의 연결 배열](https://pyqtgraph.readthedocs.io/en/pyqtgraph-0.14.0/api_reference/graphicsItems/plotdataitem.html)을
사용하여 NaN 구간 및 서로 다른 추적 구간을 연결하지 않습니다. 재생 중에는 곡선 데이터를
다시 설정하지 않고 현재 위치선/현재 측정 셀만 갱신합니다.

## 선수 추적 중단 확인

기존 위치/크기/경쟁 후보 기반 추적 알고리즘을 유지했습니다. `reselect_required`는
최초 실패 뒤 자동 재연결하지 않는 정상적인 안전 상태이며 영구 신원 인증을 뜻하지 않습니다.
새로 최초 중단 프레임/사유를 후속 프레임으로 전파하고 UI/CSV/로그에 표시합니다.

실제 `20260707_154513.mp4`에서 반대편 선수를 0번 프레임에 선택한 결과:

- 선택 세션 3: 프레임 0~72까지 73프레임 연결, 73번에서 중단.
- 최초 중단 사유: `motion_or_identity_gate` (이동/크기/신원 연속성 기준 초과).
- 직전 선택 몸통 중심 정규화 좌표: (0.7627, 0.5984), 비교용 몸통 길이 약 0.05084.
- 73번의 유일한 신뢰도 충족 후보 중심: (0.1883, 0.7955), 비교용 길이 약 0.24121.
- 위치와 크기가 크게 달라 연결을 거부했습니다. 따라서 이 사례는 단순히 전체 검출이 0명이 된
  상황이 아니라, 남아 있는 다른 위치의 후보를 선택 선수로 채택하지 않은 경우입니다.
- 73번 이후 수치는 모두 무효이며 기존 값 재사용/자동 신원 전환을 하지 않았습니다.

검출 누락·저신뢰도·후보 혼동·미분석도 별도 원인으로 기록합니다.
재선택하면 새 선택 세션 ID를 발급하고 이전 수치 전체를 폐기합니다.
동일한 선수임을 확증할 근거가 없어 이전 세션에 자동 연결하지 않습니다.
전체 영상의 정답 신원 라벨을 대조한 것이 아니므로 모든 신원 오류를 배제했다고 주장하지 않습니다.

## 한계·미검증 사항과 다음 단계

- 단일 카메라의 2D 영상 평면 값입니다. 원근/가림/카메라 회전과 검출 오차의 영향을 받습니다.
  어깨의 실제 회전, 실제 전후 몸통 굴곡, 정밀 3D 관절각 또는 부상 위험을 판단하지 않습니다.
- MediaPipe visibility/presence 기준을 만족해도 관절 위치가 틀릴 수 있습니다.
  측정 반복성은 같은 입력/알고리즘에 관한 것이며 실제 해부학적 정확도를 보증하지 않습니다.
- 영구 신원 재식별, 모든 교차/가림 조건의 신원 정답 대조, 경기 전체 길이의 메모리/안정성,
  다른 PC/코덱/화면 배율, 회전 메타데이터/비정방형 픽셀은 검증하지 않았습니다.
- 일반적인 PTS와 합성 VFR은 검증했지만 누락/역행/중복 PTS가 있는 손상 영상의 모든 유형은
  검증하지 않았습니다. 인덱싱에는 영상을 한 번 순서대로 디코딩하는 시간이 필요합니다.
- 손목 높이 정규화는 몸통이 충분히 보일 때만 유효합니다. 카메라 거리와 방향에 독립적인 3D 높이가 아닙니다.
- 다음 단계에서는 관절/신원 정답 라벨을 확보해 오차/품질을 평가하고, 장시간 캐시 용량 제한,
  신원 구간의 수동 검토/확정 및 촬영 조건·좌표계 검증을 먼저 진행하는 것이 적절합니다.
- 자세 점수·잘못된 자세 판정·스매시/클리어/동작 단계 자동 분류·LLM 코칭·부상 진단은 구현하지 않았습니다.
