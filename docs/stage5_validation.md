## 설계와 적용 범위

MediaPipe 관절 추정 → 기존 원시 관절 측정 → 스윙 이벤트 → 품질 검사 → 실제 특징 →
명시적 관찰 규칙 → 사용자 검토 흐름이다. 자세 측정과 기술적 옳고 그름 판단을 구분한다.
규칙의 기준값은 데이터 관측 충족 조건이며 배드민턴 표준 자세 기준이 아니다.
기술 표준이 검증되지 않은 V1에서는 `COACHING_AVAILABLE` 상태를 생성하지 않는다.
충분한 관측과 사용자 확인을 통과해도 `MEASUREMENT_ONLY`이며, 부족하면 `COACHING_DEFERRED`다.
추론·각도 계산·스윙·재생의 기존 코드 흐름과 JSON 형식은 보존하고 연결부만 추가했다.

## 품질 검사 및 보류

검출 품질(필요 팔/몸통 관측 수·비율), 단계 품질(자동 후보/일부 보류/사용자 확인 후보),
규칙 적용 적합성을 별도 필드로 기록한다. 관측 비율을 정확도 확률로 표현하지 않는다.

- 영상 식별/이벤트 경계/원본 PTS와 실제 표시 시간 일치 여부.
- 선택·측정·특징의 선수 ID와 추적 구간 일치. 다른 선수/구간 혼입은 무결성 실패다.
- 실제 관절 프레임/선택 프레임/측정 시각 일치, 원본 PTS의 유한성·증가·시간 간격.
- 필요한 팔/몸통 관절의 유효성, 가림·결측·고립 좌표 오류, 연속 관측 구간.
- 사용자 확인은 현재 이벤트 전체 지문에 묶는다. 경계·단계·라벨 등 변경 후에는 다시 확인한다.
- 오버헤드 적용 근거, 실제 관측된 단계, UNKNOWN_PHASE 존재, 규칙별 필수 특징과 최소 유효 비율.

기본 품질 검사에서 관측 비율 0.8 이상을 확인하지만, 기술 해석을 허용하려면 이벤트 안의
추적/관절 관측이 모두 연속이어야 한다. 결측 하나라도 있으면 보수적으로 평가를 보류한다.
규칙별 최소 비율은 0.8 또는 0.9다. 높은 비율만으로 기술적 판단을 허용하지 않는다.
단계 일부만 촬영된 경우 실제 특징은 관찰할 수 있지만 전체 해석은 보류할 수 있다.
신원/시간 무결성 실패 시 관절 수치 관찰 자체도 무효화한다.
단계 미관측이면 그 단계를 만들거나 전방/백스윙을 확정하지 않는다.

품질 보류여도 유효한 직접 관측은 별도 보여줄 수 있다. 이 경우 잠정 해석은 보류 설명으로
대체하며 개선을 단정하지 않고 근거 확인/다른 방향 추가 촬영 등의 제안만 제공한다.

## 특징 및 근거

관측값은 `Observation(name, value, unit, valid, reason, level, start_frame, end_frame, peak_frame)`으로 관리한다.
무효 값은 None이며 0으로 채우지 않는다. 아래는 실제 관측된 단계에만 계산한다.

- 준비: 시작 팔꿈치/어깨/몸통/양쪽 무릎 내각/손목 상대 높이, 변화량과 범위.
- 백스윙: 팔꿈치·어깨 변화, 손목 상대 경로, 후보 지속 시간, 각 관절 최소·최대 및 발생 프레임.
- 전방 스윙: 팔꿈치 변화·각속도, 손목 상대 속도와 피크 시각, 어깨/팔꿈치/손목 피크 시각,
  손목−팔꿈치 피크 시간 차이. 피크 시각은 영상 시간이며 실제 타격 시각이 아니다.
- 팔로스루: 팔꿈치/어깨 변화, 손목 경로·속도 변화, 몸통 변화.
- 복귀: 지속 시간, 관절/속도 변화와 유효 관측 비율로 안정화 패턴을 관찰한다.
  다음 준비 자세를 확정 관측하지 않았으므로 `next_ready_time`은 계산 불가로 남긴다.

원시 각도는 기존 관절 측정 캐시에서 읽는다. 상대 손목은 기존 몸통 정규화를 재사용한다.
코칭용 평활화·미분은 현재 이벤트 안의 관측에서 다시 계산하며 이벤트 밖의 스윙을 끌어오지 않는다.
결측/신원/시간 단절을 넘어 평활화·미분·경로 합산하지 않는다. 분석 평활화는 4단계 설정을 따르고
기존 화면 표시용 평활화와 독립적이다. 단계 미분에 필요한 이웃 표본을 포함하도록 메시지의
근거 범위를 median 반경+1프레임만큼 같은 이벤트 안에서 확장한다.
각속도는 도/초, 손목 속도는 몸통길이/초, 경로는 몸통길이, 시간은 초다.
내각·화면상 기울기/투영 운동이며 실제 3D 회전·라켓 헤드 속도·셔틀콕 임팩트를 뜻하지 않는다.

`MEASURED`(직접 원시 관측), `DERIVED`(범위·변화·속도 등 계산),
`INFERRED`(사용자 확인과 데이터 조건을 통과한 잠정 규칙 설명),
`UNDETERMINED`(판단 근거 부족)를 구분한다. 각 메시지의 실제 관측 객체 수준도 따로 보존한다.

## 초기 규칙

엔진 `local-observation-1.0`, 설정 `observation-rules-1.0`, 관절 측정 출처 `joint_angles-pts-1`,
스윙 출처 `overhead-rules-1.0`. 원본 관절 수치를 바꾸지 않고 출처 계약용 버전 이름을 기록한다.

| ID | 실제 생성 근거와 잠정 검토 범위 |
|---|---|
| backswing_elbow | BACKSWING 후보의 팔꿈치 끝−시작 변화와 변화폭. 적절한 크기인지 미판정 |
| forward_extension | FORWARD_SWING 후보의 팔꿈치 변화와 최대 절대 각속도. 신전 경향 확인 |
| peak_timing | 같은 전방 후보의 손목 속도/팔꿈치 절대 각속도 피크 시간 차이. 임팩트/이상적 연쇄 미판정 |
| follow_motion | FOLLOW_THROUGH 후보의 손목 속도·팔꿈치·어깨 변화. 감속/후속 움직임 관찰 |
| trunk_change | 실제 이벤트 시작·끝 몸통 기울기 변화와 범위. 회전/전후 굴곡/기술 결함 미판정 |
| repeat_consistency | 동일 조건 확인 후 실제 반복 관측 차이. 유사도·우수도 점수 없음 |
| quality_notice | 관측 수·단계 상태·보류 사유와 재선택/추가 촬영 안내 |

`config/coach_rules.json`은 ID/이름/버전/사용 여부, 적용 종류/단계/관절/특징, 최소 관측 비율,
조건·관찰 방법·잠정 해석·제안·보류 기준을 명시한다. 동작 실행은 허용된 ID의 코드에 한정한다.
조건 설명 문자열을 eval/임의 코드로 실행하지 않으며 임의의 새 규칙 수식은 V1 범위가 아니다.
설정 파일 불러오기 및 파일 변경 감지(1초)를 지원한다. 버전 이름이 같아도 내용 지문이 바뀌면 무효화한다.
잘못된 설정은 코칭을 중단하고 로그/상태줄에 원인을 알리며 플레이어는 유지한다.

## UI 및 반복 비교

접이식 AI 코칭 패널과 분석/선택·전체 분석/취소/근거 영상/근거 반복/저장/초기화 컨트롤을 추가했다.
기존 스윙 선택 시 관련 코칭 결과로 바뀐다. 상태 A → 관찰 B → 검토 C → 제안 D 순서로 표시한다.
기본 목록은 실제 관측 또는 품질 안내를 최대 3개만 표시한다. 미관측 단계 보류 항목으로 억지로 채우지 않는다.
나머지 펼치기, 숨긴 결과 보기, 단계별 측정 근거, 반복 관찰 차이 탭을 제공한다.

결과 목록을 클릭하면 해당 근거의 첫 프레임을 탐색하고 관련 관절 그래프 표시를 켠다.
그래프와 기존 스윙 타임라인에 별도 근거 영역을 강조한다. 기존 A/B 범위·통계는 변경하지 않는다.
근거 구간 반복과 기존 스윙 반복은 별도 사용 흐름으로 유지한다. 오래된/다른 선수 근거는 탐색·반복을 차단한다.
패널은 접거나 분할선을 조절할 수 있다. 모두 펼쳤을 때 가용 영상 영역은 창 크기에 따라 줄어든다.

반복 비교는 다음 전제를 모두 통과해야 한다.

- 같은 원본 영상, 선수 문맥·ID·추적 구간, 라켓 손, 알려진 동일 후보 종류.
- 각 이벤트의 사용자 스윙/단계 확인과 충분한 연속 데이터.
- 사용자가 같은 고정 촬영 각도·동일 기술임을 확인하고 비교 그룹을 입력함.

촬영/기술이 실제 같은지는 자동 추정하지 않으며 재실행 시 이 조건을 다시 확인한다.
같은 영상이라도 줌/회전/촬영 방향이 달라졌다면 확인하면 안 된다.
비교 항목: 전체/전방 후보 지속 시간, 팔꿈치/어깨 범위, 시작 대비 손목 피크 위치,
몸통 변화, 관측 비율. 동일 문맥의 다른 확인 이벤트를 기준으로 현재/기준/차이/단위를 보여준다.
부족한 항목은 비교 불가 이유를 표시한다. 서로 다른 기술을 동일 기술 일관성으로 자동 취급하지 않는다.

## 저장·검토·캐시

`CoachReport`는 영상/문맥/이벤트 지문/전체 입력 지문, 엔진·규칙·관절·동작 버전,
생성 시각, 품질, 메시지, 단계별 특징과 반복 비교를 보존한다.
`CoachMessage`는 결과 ID, 선수/추적 구간, 관련 단계, 규칙 ID/버전, 측정값·단위/유효성,
근거 프레임·원본 PTS, 관찰/해석/제안, 품질/보류 이유, 자동 출처와 생성 시각을 가진다.
사용자 검토는 `CoachReview`에 분리하고 결과 원문은 자동 생성 출처를 유지한다.

사용자는 확인/판단 보류/분석 오류(이유 필수), 메모, 숨김을 적용·취소한다.
숨긴 결과 보기를 켜고 숨김을 해제하면 복원된다. 사용자 검토는 학습 데이터 자동 학습으로 연결되지 않는다.
메모/검토 이력은 자동 재분석 때 삭제하지 않는다. 검토가 연결된 입력 지문이 달라지면
이전 근거 검토·재확인 필요로 표시한다. 이벤트 확인과 코칭 결과 확인은 별도 기능이다.

저장: `output/coaching/<영상 지문>.json`, schema 1. 원본 스윙 JSON/설정 키를 변경하지 않고
별도 저장하므로 기존 1~4단계 데이터 마이그레이션은 필요 없다. 임시 파일+원자적 replace를 사용한다.
원본 영상 식별, 이벤트 스냅샷, 선수/근거 프레임/PTS, 관측값의 유한성과 범위를 검사한다.
손상된 기존 기록을 빈 기록으로 자동 덮어쓰지 않는다. 저장 실패 시 메모리를 보존하고 종료 때 재시도한다.
초기화/재분석 전 보고서와 사용자 작업 이력을 남긴다. CSV(BOM)/JSON 내보내기는
품질·버전·근거·검토·stale 표시를 포함한다. CSV 문자열 수식 실행 방지 처리를 적용한다.

입력 지문은 실제 관절·선택·측정 데이터, 시간축/영상, 스윙 문서, 설정/규칙 내용,
사용자 확인과 비교 조건 전체로 계산한다. 동일 입력이면 이전 보고서를 재사용한다.
이 작업도 QThread에서 수행한다. UI는 입력 변경 신호와 작업 세대를 검사해 늦게 온 결과를 폐기한다.
영상/선수/손/측정/스윙/단계/규칙 변경은 재검토하며 과거 JSON은 재분석 전 항상 과거 기록으로 표시한다.
포즈 추론이나 디코딩을 코칭을 위해 호출하지 않는다.

## 실행 및 검증

```powershell
.\.venv\Scripts\python.exe -m app.main
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests/run_pose_smoke.py --coach
```

자동 테스트는 기존 54개와 신규 순수 코칭 20개/Qt 코칭 12개로 구성한다.
전체 86개 테스트가 통과했다(31.396초). 실제 모델 통합 결과는 아래 산출물에 기록한다.

- `output/stage5_tests.txt`: 전체 회귀 테스트 실행 로그.
- `output/coach_smoke_report.json`: 실제 MP4 통합 결과 및 `real_coaching_accuracy_validated: false`.
- `output/coach_smoke_panel.png`, `coach_smoke_overlay.png`, `coach_smoke_original.png`: 실제 Windows 화면.
- `output/coach_smoke_results.json`, `coach_smoke_results.csv`: 테스트 보고서 내보내기.
- `output/coach_smoke_events/<실행시각>`: 사용자 데이터와 분리한 테스트 저장소.

테스트 범위: 기존 1~4단계 전체 회귀, 실제 원시값으로 메시지 생성, 좌우 손,
추적/선수·구간 혼입/프레임·PTS 불일치 보류, UNKNOWN 단계 비생성, None/NaN 비조작,
실제 수치 및 근거 범위/PTS, 이벤트·단계·규칙·캐시 내용 변경, 조건부 반복 비교,

UI heartbeat/취소·오류 후 복구/현재 캐시 재사용, 근거 목록 마우스 클릭·그래프·영상/A-B 격리.
의도적인 손상 MP4·없는 모델·작업 예외 테스트의 진단 로그는 예상 출력이다.

실제 통합 영상은 `data/videos/20260707_154513.mp4`(1920×1080, 276프레임, 약 9.198초)다.
실제 MediaPipe 분석·다인 마우스 선택·PTS·측정·CSV·스윙 수동 수정/재로딩을 거친다.

스윙 후보 [14,55], [56,72]는 둘 다 UNKNOWN/UNKNOWN_PHASE다.
코칭 보고서 2개/규칙 안내 14개 모두 평가 보류이며 품질 부족이나 미확인 단계로부터 기술 판단을 만들지 않는다.
실제 근거 프레임 이동·그래프 연결, 테스트 검토 메모 저장/복원·내보내기와 원본 표시를 확인한다.

모델 분석 중 UI 타이머 676회, 코칭 중 6회 응답했으며 근거 frame 14의 원본 PTS/그래프 일치를 확인했다.
후보 내부의 유효 관측은 각각 42/42, 17/17이어도 단계/사용자 확인이 부족해 평가를 보류했다.
이 비율은 영상 전체 추적 성공률이나 기술 정확도를 의미하지 않는다.
통합 검증의 수동 라벨/메모는 기능 검증용이며 스포츠 전문가의 정답 라벨이 아니다.
추가 네이티브 합성 포인터 클릭 검증 중 이벤트 재진입 대기가 발생해 해당 테스트 프로세스만
종료했다. 코칭 클릭 도중 동일 스윙/목록을 재구성하는 경로를 제거했다.
자동 Qt 테스트의 실제 QTest 목록 클릭은 통과했으며, 실제 모델 GUI 통합은 목록 선택 신호로
검증한다. 네이티브 포인터 주입 성공이나 실제 사람이 클릭한 검증으로 보고하지 않는다.

## 미검증 사항과 다음 단계

실제 기술 평가의 타당성/지도 효과는 합성 테스트나 이번 통합 실행으로 검증되지 않았다.
이번 실제 영상은 단계가 보류됐으므로 실제 경기의 정상 코칭 해석 정확도를 입증하지 않는다.
실제 왼손 선수, 다양한 구도·프레임률·줌/회전·가림·복장/교차 상황과 여러 기술은 추가 검증이 필요하다.
사용자의 동일 촬영/기술 확인도 전문가 검증을 대신하지 않는다. 2D 기울기와 경로는 카메라 영향을 받는다.
보수적인 연속성 조건 때문에 일부 측정이 있어도 해석을 보류할 수 있다.
다음 준비 자세까지 시간은 확정 관측이 없어 계산하지 않으며 장시간 영상 부하/이력 용량은 미검증이다.

향후 지도자가 검토한 원본 영상/이벤트/단계/규칙별 정답과 사용자 오류 이유를 확보해
경계 오차·규칙 적용 타당성·촬영 조건별 한계를 검증해야 한다. 검토 상태를 자동 정답으로 취급하면 안 된다.
규칙별 충분한 근거가 확보된 뒤에만 기술 기준을 도입하고 측정/해석/보류 및 출처를 계속 분리해야 한다.
