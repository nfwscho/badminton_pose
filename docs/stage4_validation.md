## 구성과 기존 기능 보존

원본 PTS, 기존 MediaPipe/선수 추적/관절 측정 캐시를 입력으로 사용하는 독립 분석 모듈을 추가했다.
QThread는 불변 데이터 스냅샷에서 계산하며 영상 재디코딩과 포즈 재추론을 하지 않는다.
플레이어·메인 UI는 필요한 연결부만 확장했다. 기존 재생/탐색/CSV/측정·표시 평활화/로그는 유지한다.
스윙 패널은 접을 수 있으며 기존 그래프/영상과 분할선을 공유한다.
이벤트 선택에 따른 그래프 표시 범위와 기존 A/B 통계 범위를 분리했다.
일반 탐색/프레임 이동은 선택 구간 반복 재생을 해제한다.

## 검출 규칙: overhead-rules-1.0

1. 라켓 손을 사용자가 명시적으로 선택한다. 왼손이면 왼쪽 손목/팔꿈치/어깨 측정값을 사용한다.
   손 설정을 바꾸면 기존 결과를 현재 분석과 구분한다. 라켓 자체는 검출하지 않는다.
2. 선택/추적된 동일 선수, 동일 추적 구간이며 몸통 네 관절과 해당 팔의 신뢰도가 충분해야 한다.
   손목을 어깨 중심에 상대화하고 연속 관측 구간의 몸통 길이 중앙값으로 정규화한다.
   공통적인 화면 평행 이동은 완화하지만 카메라 회전/줌/투영 변화는 보정하지 못한다.
3. 기본 분석 평활화는 3표본 median이며 none/홀수 윈도 1–15를 설정할 수 있다.
   7표본 주변 대비 고립된 큰 좌표 오차는 유효 관측에서 제외하고 대체 좌표를 만들지 않는다.
   기존 화면 표시용 평활화 및 원본 캐시는 변경하지 않는다.
4. 실제 PTS 간격으로 손목 속도와 팔꿈치/어깨/몸통 각속도를 계산한다.
   결측/다른 신원/중복·역행 PTS/대체 시간/기본 0.15초 초과 간격에서 연속 구간을 끊는다.
   구간을 넘는 보간·평활화·미분·후보 병합은 하지 않는다.
5. 각 연속 구간의 속도 20백분위 baseline과 하위 절반의 잡음 중앙편차를 사용한다.
   높은 기준 = max(1.4/민감도, baseline + 3×max(잡음, 0.05)/민감도),
   낮은 기준 = max(0.18, 높은 기준×0.4). 기본 민감도 1이다.
6. 기본 최소 활동 지속 0.18초, 상대 손목 이동폭 0.35 몸통 길이와 높은 기준 이상의 피크를 요구한다.
   팔꿈치/어깨 변화폭 12도 이상 또는 손목 상대 높이 변화 0.2 이상도 필요하다.
   같은 관측 구간에서만 기본 0.12초 이내 후보를 병합한다. 충분히 깊고 지속적인 속도 골과
   피크 간격이 있어야 별도 스윙으로 나눠 백스윙/전방 스윙 피크의 중복 검출을 줄인다.
7. 앞뒤 최대 0.30초 관측 문맥을 포함하되 다른 이벤트/단절을 넘지 않는다.
   손목이 어깨보다 0.1 몸통 길이 이상 높은 관측이 0.06초 이상이고 어깨각 70도 또는 높이 0.3
   근거가 있으면 OVERHEAD_CANDIDATE다. 높이 관측 비율은 기본 70% 이상이어야 한다.
   충분한 움직임이 낮은 위치에 머무르면 OTHER_SWING, 근거가 부족하면 UNKNOWN이다.
   A/B에서 잘려 최소 시간을 채우지 못한 후보는 UNKNOWN/잘림으로 남길 수 있다.
8. 유효 관측에서 후보가 없는 구간 NO_SWING과 분석 불가 UNKNOWN을 별도 커버리지로 기록한다.
   후보 UNKNOWN은 `swing_candidate` 사유로 구분한다. 이벤트 유효 비율은 후보 내부 관측 비율이며
   전체 영상 관측 비율이나 분류 확률이 아니다. UI에 분석 범위 유효 관측 수도 별도 표시한다.

움직임 강도 = 손목 속도² + 0.25×(팔꿈치 각속도/180)²
+ 0.15×(어깨 각속도/180)² + 0.1×(몸통 각속도/90)².
사용 가능한 항만 더한다. 신호 탐색용 지표이며 줄(J)이나 생체역학 에너지가 아니다.
손목 경로 길이는 유효한 인접 관측만 합산한다. 단위는 몸통 길이, 속도는 몸통 길이/초,
각속도는 도/초다. 신체 표면 거리/라켓 헤드 속도를 의미하지 않는다.

## 단계 판단 근거

OVERHEAD_CANDIDATE에만 자동 세부 단계를 적용한다. 균등 시간 분할은 하지 않는다.

| 단계 | 필요한 관측 근거 |
|---|---|
| READY | 활동 전 낮은 속도가 최소 0.08초 안정적으로 유지됨 |
| BACKSWING | 속도 피크 전 손목 상대 높이의 0.12 이상 상승 및 높이 전환점 |
| FORWARD_SWING | 전환 이후 속도 피크까지 유의한 가속과 팔꿈치/어깨 변화폭 8도 이상 |
| FOLLOW_THROUGH | 피크 이후 관측된 감속, 속도가 피크의 85% 아래로 감소 |
| RECOVERY | 피크 이후 낮은 속도의 0.08초 이상 안정화; 실제 준비 자세 복귀 보장은 아님 |
| UNKNOWN_PHASE | 해당 근거 부족, 미관측 또는 일부만 관측된 부분 |

각 단계는 프레임과 시작/끝 표시 시간, 원본 시작/끝 PTS를 가진다.
표시 종료 시간은 마지막 프레임이 끝나는 시각이므로 마지막 프레임 시작 PTS와 다르다.
역순/겹침/이벤트 밖 경계를 거부하고 빈 부분은 UNKNOWN_PHASE로 채운다.
단일 시점의 2D 이동을 실제 전방/후방 또는 타격 순간이라고 확정하지 않는다.

## UI, 저장 및 수동 수정

목록 7열: 순번/시작/끝/길이/후보/단계 상태/유효 비율. 후보가 없으면 명시한다.
상세 탭에는 단계 길이, 손목 상대 경로, 팔꿈치/어깨 최소·최대, 전방 단계 팔꿈치 변화,
손목/강도 피크와 근거·불확실성을 표시한다. 값 부족은 계산 불가이며 0으로 채우지 않는다.
타임라인은 전체 시간, 단계별 색, 선택 강조, 관측 불가 구간, 현재 프레임을 표시한다.
기존 pyqtgraph 그래프와 X축을 연결하고 클릭/확대/초기화를 지원한다.
선택 이벤트 단계 경계는 기존 그래프에도 표시한다. 프레임마다 전체 곡선은 다시 만들지 않는다.
단계 배지는 영상 밖에 있어 기존 골격·각도 토글을 끄면 원본 영상 그대로 볼 수 있다.

편집 대화상자는 별도 입력에서 적용/취소한다. 이벤트 범위, 후보, 사용자 라벨과 단계 경계를
수정하며 추가/삭제/전체 자동 복원을 지원한다. 다른 이벤트와 겹치는 범위는 거부한다.
자동 원본과 사용자 수정본을 분리하고 변경 종류/시각을 기록한다.
수동 변경 문서를 자동 재분석 등으로 교체할 때 확인하며 거절하면 기존 문서를 유지한다.

JSON 기본 경로는 `output/motion_events/<영상 fingerprint>.json`이다.
영상 경로/크기/mtime, 선택 기준 프레임·몸통 위치, 손 설정, 알고리즘 버전으로 문맥을 구분한다.
자동 결과/현재 수정본/이전 문서 이력/마지막 문맥을 원자적으로 저장한다.
동일 저장을 반복해 이력을 중복 추가하지 않는다. 손/선수별 문맥을 선택해 불러올 수 있다.
로드 때 영상/문맥/버전/범위/타임스탬프/이벤트·단계 겹침/커버리지 연속성을 검사한다.
선수 ID는 영구 신원이 아니며 과거 JSON은 스냅샷이다. 현재 새 측정 캐시와 자동 결합하지 않는다.
저장 실패 문서를 메모리에 보존하고 종료 시 다시 저장하며 저장 불가하면 종료를 보류한다.
취소/영상 교체/손·설정·A/B 변경 후 늦게 도착한 작업 결과는 현재 결과를 덮어쓰지 않는다.

- 기존 A/B 31행 원시 CSV 일치, 그래프 클릭 탐색/타임라인 실제 클릭 동기화 통과.
- 테스트용 라벨 수정 → JSON 저장 → 재로딩 동일성 확인. 이는 스포츠 전문가의 정답 보정이 아니다.
  사용자 보정 파일과 별도인 `output/motion_smoke_events/<실행시각>`에 저장했다.
- 분석 중 50ms UI 타이머 733회 응답. 전체 실행 51.62초, 모델 분석 약 46초.
- 골격/각도 OFF 원본 프레임 일치. 창 크기 조정 및 목록/타임라인/원본 스크린샷 육안 점검.
- `output/motion_smoke_report.json`: `passed: true`, `real_motion_accuracy_validated: false`.
- 화면: `output/motion_smoke_list.png`, `output/motion_smoke_overlay.png`,
  `output/motion_smoke_original.png`. 최종 경미한 상태 문구·설정 복원·JSON 검증 강화 후에는
  자동 54개 회귀 테스트를 재실행했으며 전체 실제 모델 통합 실행은 반복하지 않았다.

## 미검증 사항과 한계

실제 영상의 스윙 시작/끝·각 단계에 대한 전문가 정답 대비 정밀도/재현율/경계 오차는 미검증이다.
이번 실제 영상은 오버헤드 단계를 자동 확정하지 못했으며 다섯 단계 실제 경기 정확도를 입증하지 않는다.
다양한 선수·촬영 각도·줌/카메라 이동·조명·프레임률·좌우 손·가림·복장·교차 상황의
별도 실제 데이터셋 검증이 필요하다. 장시간 영상의 메모리/저장 이력 증가·부하도 미검증이다.
보수적 신원 중단 이후에는 재선택해야 하며 잃어버린 신원을 자동 복구하지 않는다.
고정된 규칙/기본값은 보편적인 운동학 기준으로 보정되지 않았다. 포핸드 여부도 확정하지 않는다.
다섯 단계 모두 관측돼야 한다고 강제하지 않으며 안정화가 실제 복귀 자세와 같지는 않다.
움직임만으로 타격/라켓/셔틀콕을 판정하지 않는다. 코칭 점수·교정·부상 위험 판단은 구현하지 않았다.

## 5단계에서 사용할 출력

MotionResult와 MotionEvent에는 영상/선수 문맥·추적 구간·손·알고리즘 버전,
프레임/정규화 시간/원본 PTS, 분류/단계 경계, 피크 시점·피크 관절각,
유효 비율·관측 제외 사유, 단계 길이·상대 경로·관절 범위·전방 각도 변화·강도 지표,
자동/수동 출처와 근거/불확실성 및 작업 이력이 있다.
향후 엔진은 측정과 코칭 판단을 분리하고 이 유효성·불확실성 정보를 먼저 확인해야 한다.
전문가 보정 정답을 별도 확보해 검출/경계/단계 정확도를 검증한 뒤 규칙 보정 또는 학습 모델과
비교해야 하며, 합성 테스트 통과를 근거로 코칭 판단을 생성하면 안 된다.
