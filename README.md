# Badminton AI Coach — 동영상 플레이어 및 AI 관절 시각화

Windows 10 / Python 3.12 / PySide6 기반 데스크톱 프로그램입니다.
기존 플레이어에 MediaPipe 관절 인식·선수 선택·골격 시각화를 추가했습니다.
관절 각도 평가, 동작 분류, 코칭 점수 및 교정 메시지는 구현하지 않았습니다.

## 실행 (PowerShell, 프로젝트 폴더)

```powershell
.\.venv\Scripts\python.exe -m app.main
```

직접 실행도 가능합니다: `.\.venv\Scripts\python.exe app\main.py`.
현재 프로젝트의 `.runtime`에는 Python 3.12.15가 있으며 `.venv`가 이를 사용합니다.
두 폴더를 이동하거나 삭제하면 가상환경을 다시 생성해야 합니다.
다른 PC에서 설치된 Python 3.12를 사용하는 경우:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 조작

- MP4 동영상 불러오기: 버튼 또는 Ctrl+O
- 재생 / 일시정지: 버튼 또는 Space
- 이전 / 다음 프레임: 버튼 또는 좌우 방향키 (이동하면 일시정지)
- 재생 위치: 슬라이더 클릭 또는 드래그 후 놓기 (이동하면 일시정지)
- 영상 끝에서는 일시정지하며 재생을 누르면 처음부터 시작합니다.
- 영상은 비율을 유지해 표시합니다. 현재 시간과 전체 시간은 밀리초까지 표시합니다.

## AI 관절 분석 및 선수 선택

1. MP4를 불러오고 **AI 자세 분석**을 누릅니다. 재생 디코더와 별개의 QThread가
   프레임을 순서대로 분석합니다. 분석 중에도 재생/탐색을 사용할 수 있습니다.
2. 진행률과 현재 프레임의 검출/캐시 상태를 확인합니다. **분석 취소**는 현재 추론
   호출이 끝난 뒤 중단하며, 처리한 프레임의 부분 캐시는 유지합니다.
3. 완료 또는 취소 후 몸통 관절이 잘 보이는 프레임으로 이동하고 **선수 선택**을
   누른 뒤 영상의 선수를 클릭합니다. 재생은 일시정지됩니다. 영역이 겹치거나
   신뢰도가 부족하면 선택을 보류하므로 다른 프레임/위치에서 다시 선택하세요.
4. 선택 프레임을 기준으로 앞뒤 연속 프레임의 추적 결과를 별도 스레드에서 계산합니다.
   선택 선수는 왼쪽 노랑/오른쪽 자홍과 노란 테두리, 나머지는 왼쪽 초록/오른쪽 파랑입니다.
5. 가림/검출 누락/급격한 이동/다른 선수와의 혼동 위험 시 추적을 중단합니다.
   이후 자동으로 다른 선수나 재등장한 선수에 연결하지 않습니다. 필요한 프레임에서
   다시 선택하세요. **선수 선택 해제**는 전체 선택과 추적 결과를 지웁니다.
6. **골격 표시 ON/OFF**를 끄면 보존된 원본만 표시합니다. 이 설정은 종료 시 저장합니다.
   화면 크기를 바꿔도 원본 비율과 레터박스 여백을 기준으로 표시/클릭 위치를 맞춥니다.

최대 4명을 요청하며, 실제 검출 인원은 영상에 따라 적을 수 있습니다.
와이드 화면에서 작은 선수의 누락을 줄이기 위해 전체 영상과 좌/우의 겹치는
60% 영역을 각각 독립 VIDEO 인스턴스로 분석합니다. 영역 좌표를 원본으로
역변환하고 몸통 관절이 거의 같은 중복 후보는 신뢰도 높은 결과 하나로 합칩니다.
이 때문에 전체 화면 1회 추론보다 처리 시간과 모델 메모리 사용량이 증가합니다.
각 관절의 visibility와 presence가 모두 0.5 이상이고 화면 안의 유효 좌표일 때만
표시합니다. 양 끝 관절이 유효한 연결선만 표시하며 이전 프레임 좌표를 보충하지 않습니다.
선수 선택/추적은 어깨와 골반 네 관절의 신뢰도를 모두 요구합니다.

모델은 `models/pose_landmarker_full.task`를 사용합니다. 공식 출처와 버전/해시는
[models/README.md](models/README.md)에 기록했습니다. 모델이 없어도 플레이어는 실행됩니다.
MediaPipe 의존성과 OpenCV 중복 설치를 피하기 위해 `opencv-python`을 동일 4.13 계열의
`opencv-contrib-python`으로 대체했습니다. 기존 재생 코드의 cv2 API는 유지합니다.

## 분석 데이터와 캐시

- `AnalysisCache.frames[프레임 번호]`: 불변 `FrameResult` — 프레임 번호, 밀리초 시간,
  검출 성공/상태, 다인 `PersonPose` 목록을 관리합니다.
- `PersonPose.joints`: 관절 ID/이름, 정규화 x/y, 상대 깊이 z, visibility/presence,
  제공되는 경우 미터 단위 월드 x/y/z를 가진 33개 `Joint`입니다.
  `in_source_view`는 추론 영역 안에서 관측된 좌표인지를 나타내며,
  `PersonPose.source_view`는 전체/좌/우 추론 영역의 출처입니다.
  월드 좌표는 각 영역의 모델 추정값이며 카메라 보정이나 정밀 3D 측정값이 아닙니다.
- `AnalysisCache.selections[프레임 번호]`: `FrameSelection` — 선택 세션 안의 선수 ID,
  해당 프레임의 pose 인덱스 또는 None, 추적 상태를 별도로 관리합니다.
  MediaPipe의 출력 순서와 영구 인물 ID는 서로 다릅니다.
- 캐시 상태: 없음/분석 중/완료/취소 부분 결과/오류 부분 결과/무효.
  파일 경로·크기·mtime, 모델 SHA-256, MediaPipe 버전, 검출 설정으로 식별합니다.
  선수 선택 전에 변경 여부를 확인하며, 영상 다시 열기/AI 재분석 시 캐시를 초기화합니다.
- 재생 시 디스플레이 프레임 번호에 정확히 대응하는 캐시만 조회합니다.
  미분석·미검출·신뢰도 부족·추적 실패는 구분하여 표시합니다.
- VIDEO 모드에는 `round(frame_index * 1000 / fps)`를 사용하고 이전 값보다 최소 1ms
  증가시킵니다. 각 분석 때 모델 인스턴스를 새로 만들므로 뒤로 탐색해도 VIDEO 상태를 재사용하지 않습니다.
  플레이어와 같은 FPS 시간축이며 VFR의 원본 PTS 동기화는 후속 과제입니다.
- 원본 프레임 전체를 캐시하지 않지만 긴 영상의 다인 관절 데이터는 메모리를 많이 사용합니다.
  캐시는 메모리에만 있으며 앱 종료 시 사라집니다. 선택 중단 이후의 영구 신원 복구는 지원하지 않습니다.

디코딩은 별도 작업 스레드에서 수행합니다. 이번 버전은 영상만 재생하며
오디오는 지원하지 않습니다. OpenCV가 지원하는 코덱의 MP4를 사용하세요.
프레임 시간은 파일 FPS 기준이며 가변 프레임률 영상은 실제 타임스탬프와 차이가 날 수 있습니다.

## 로그 및 설정

- `logs/app.log`: 실행, 열기, 재생, 탐색, 종료 및 오류 추적을 누적 기록합니다.
- `output/settings.ini`: 창 크기/위치/상태, 골격 표시 설정과 마지막 파일 선택 폴더를 저장합니다.
- 기본 창 크기: 1100×760, 최소 크기: 640×420.
- 마지막 영상을 자동으로 열거나 재생하지 않습니다.

## 테스트

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

테스트는 임시 MP4와 오프스크린 Qt를 사용하여 실제 디코딩, 재생/일시정지,
프레임 탐색/경계, 파일 오류 후 복구, 설정 복원을 확인합니다. AI 자동 테스트는
합성 관절 및 가짜 검출기를 사용해 신뢰도 필터, 신원 연결 중단, 분석 취소/오류,
UI 응답, 캐시 동기화와 오버레이 좌표를 검증합니다.

실제 모델/MP4 전체 분석 및 Windows GUI 통합 검증:

```powershell
.\.venv\Scripts\python.exe tests/run_pose_smoke.py --video data/videos/20260707_154513.mp4
```

영상 경로를 생략하면 `data/videos`의 첫 MP4를 사용합니다. `--offscreen`으로
디스플레이 없이도 실행할 수 있습니다. 검증 후 자동 종료하며 JSON 결과와
골격 ON/OFF 화면을 `output/pose_smoke_*`에 저장합니다.

실제 영상의 모든 프레임에 대한 관절 정답 대조 및 신원 정확도 수치 평가는 수행하지 않습니다.
일반적인 가림/유사 복장/교차 상황에서 잘못 연결될 가능성을 완전히 제거하지 못합니다.
관절 위치의 연속성 검사는 보수적으로 연결을 중단하며 영구 신원 보장을 제공하지 않습니다.
거리/운동/가림에 따른 미검출과 표시 제한은 모델 및 촬영 조건의 제약입니다.
상세 검증 결과는 [2단계 검증 기록](docs/stage2_validation.md)을 확인하세요.
