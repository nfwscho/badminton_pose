# Badminton AI Coach — 동영상·스윙 분석·근거 기반 코칭 관찰

Windows 10 / Python 3.12 / PySide6 기반 데스크톱 프로그램입니다.
기존 플레이어에 MediaPipe 관절 인식·선수 선택·골격 시각화와 2D 관절 측정을 추가했습니다.
4단계에서는 기존 캐시를 사용하는 규칙 기반 스윙 후보·동작 단계 분석을 추가했습니다.
5단계에서는 품질 검사를 거치는 로컬 규칙 기반 코칭 관찰·검토 패널을 추가했습니다.
분류 결과는 수동 검토가 필요한 후보입니다. 표준 자세 대비 우수/불량 판정과 코칭 점수는 제공하지 않습니다.

## 실행 (PowerShell, 프로젝트 폴더)

```powershell
.\.venv\Scripts\python.exe -m app.main
```

직접 실행도 가능합니다: `.\.venv\Scripts\python.exe app\main.py`.
현재 프로젝트의 `.runtime`에는 Python 3.12.15가 있으며 `.venv`가 이를 사용합니다.
두 폴더를 이동하거나 삭제하면 가상환경을 다시 생성해야 합니다.
다른 PC에서 설치된 Python 3.12를 사용하는 경우:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 조작

- MP4 동영상 불러오기: 버튼 또는 Ctrl+O
- 재생 / 일시정지: 버튼 또는 Space
- 이전 / 다음 프레임: 버튼 또는 좌우 방향키 (이동하면 일시정지)
- 재생 위치: 슬라이더 클릭 또는 드래그 후 놓기 (이동하면 일시정지)
- 영상 끝에서는 일시정지하며 재생을 누르면 처음부터 시작합니다.
- 영상은 비율을 유지해 표시합니다. 현재 시간과 전체 시간은 밀리초까지 표시합니다.

## AI 관절 분석 및 선수 선택

1. MP4를 불러오고 **AI 자세 분석**을 누릅니다. 재생 디코더와 별개의 QThread가
   프레임을 순서대로 분석합니다. 분석 중에도 재생/탐색을 사용할 수 있습니다.
2. 진행률과 현재 프레임의 검출/캐시 상태를 확인합니다. **분석 취소**는 현재 추론
   호출이 끝난 뒤 중단하며, 처리한 프레임의 부분 캐시는 유지합니다.
3. 완료 또는 취소 후 몸통 관절이 잘 보이는 프레임으로 이동하고 **선수 선택**을
   누른 뒤 영상의 선수를 클릭합니다. 재생은 일시정지됩니다. 영역이 겹치거나
   신뢰도가 부족하면 선택을 보류하므로 다른 프레임/위치에서 다시 선택하세요.
4. 선택 프레임을 기준으로 앞뒤 연속 프레임의 추적 결과를 별도 스레드에서 계산합니다.
   선택 선수는 왼쪽 노랑/오른쪽 자홍과 노란 테두리, 나머지는 왼쪽 초록/오른쪽 파랑입니다.
5. 가림/검출 누락/급격한 이동/다른 선수와의 혼동 위험 시 추적을 중단합니다.
   이후 자동으로 다른 선수나 재등장한 선수에 연결하지 않습니다. 필요한 프레임에서
   다시 선택하세요. **선수 선택 해제**는 전체 선택과 추적 결과를 지웁니다.
6. **골격 표시 ON/OFF**로 골격을 숨길 수 있습니다. 각도 표시가 켜져 있다면
   **관절 각도 표시 ON/OFF**도 끄면 보존된 원본만 표시합니다. 두 설정은 독립적으로 저장됩니다.
   화면 크기를 바꿔도 원본 비율과 레터박스 여백을 기준으로 표시/클릭 위치를 맞춥니다.

최대 4명을 요청하며, 실제 검출 인원은 영상에 따라 적을 수 있습니다.
와이드 화면에서 작은 선수의 누락을 줄이기 위해 전체 영상과 좌/우의 겹치는
60% 영역을 각각 독립 VIDEO 인스턴스로 분석합니다. 영역 좌표를 원본으로
역변환하고 몸통 관절이 거의 같은 중복 후보는 신뢰도 높은 결과 하나로 합칩니다.
이 때문에 전체 화면 1회 추론보다 처리 시간과 모델 메모리 사용량이 증가합니다.
각 관절의 visibility와 presence가 모두 0.5 이상이고 화면 안의 유효 좌표일 때만
표시합니다. 양 끝 관절이 유효한 연결선만 표시하며 이전 프레임 좌표를 보충하지 않습니다.
선수 선택/추적은 어깨와 골반 네 관절의 신뢰도를 모두 요구합니다.

모델은 `models/pose_landmarker_full.task`를 사용합니다. 공식 출처와 버전/해시는
[models/README.md](models/README.md)에 기록했습니다. 모델이 없어도 플레이어는 실행됩니다.
MediaPipe 의존성과 OpenCV 중복 설치를 피하기 위해 `opencv-python`을 동일 4.13 계열의
`opencv-contrib-python`으로 대체했습니다. 기존 재생 코드의 cv2 API는 유지합니다.

## 분석 데이터와 캐시

- `AnalysisCache.frames[프레임 번호]`: 불변 `FrameResult` — 프레임 번호, 밀리초 시간,
  검출 성공/상태, 다인 `PersonPose` 목록을 관리합니다.
- `PersonPose.joints`: 관절 ID/이름, 정규화 x/y, 상대 깊이 z, visibility/presence,
  제공되는 경우 미터 단위 월드 x/y/z를 가진 33개 `Joint`입니다.
  `in_source_view`는 추론 영역 안에서 관측된 좌표인지를 나타내며,
  `PersonPose.source_view`는 전체/좌/우 추론 영역의 출처입니다.
  월드 좌표는 각 영역의 모델 추정값이며 카메라 보정이나 정밀 3D 측정값이 아닙니다.
- `AnalysisCache.selections[프레임 번호]`: `FrameSelection` — 선택 세션 안의 선수 ID,
  해당 프레임의 pose 인덱스 또는 None, 추적 상태를 별도로 관리합니다.
  MediaPipe의 출력 순서와 영구 인물 ID는 서로 다릅니다.
- 캐시 상태: 없음/분석 중/완료/취소 부분 결과/오류 부분 결과/무효.
  파일 경로·크기·mtime, 모델 SHA-256, MediaPipe 버전, 검출 설정으로 식별합니다.
  선수 선택 전에 변경 여부를 확인하며, 영상 다시 열기/AI 재분석 시 캐시를 초기화합니다.
- 재생 시 디스플레이 프레임 번호에 정확히 대응하는 캐시만 조회합니다.
  미분석·미검출·신뢰도 부족·추적 실패는 구분하여 표시합니다.
- PyAV가 원본 표시 순서의 PTS를 백그라운드에서 인덱싱합니다. 플레이어 시간,
  재생 간격, 그래프, A/B, 측정 CSV는 첫 표시 프레임을 0초로 한 원본 시간축을 사용합니다.
  PTS 누락/역행에만 FPS 시간을 대체하며 UI/로그/CSV에 명시합니다.
  인덱싱 중에는 기존 플레이어의 FPS 추정 시간을 표시하고 수치 분석은 기다립니다.
- `FrameResult.timestamp_seconds`는 원본 시간, `timestamp_ms`는 그 반올림값,
  `model_timestamp_ms`는 MediaPipe VIDEO용 단조 증가 보정 시간입니다.
  VIDEO에는 원본 시간을 밀리초로 반올림하되 이전 입력보다 최소 1ms 증가시킵니다.
  각 분석 때 모델을 새로 만들므로 뒤로 탐색해도 VIDEO 상태를 재사용하지 않습니다.
- 원본 프레임 전체를 캐시하지 않지만 긴 영상의 다인 관절 데이터는 메모리를 많이 사용합니다.
  캐시는 메모리에만 있으며 앱 종료 시 사라집니다. 선택 중단 이후의 영구 신원 복구는 지원하지 않습니다.

디코딩은 별도 작업 스레드에서 수행합니다. 이번 버전은 영상만 재생하며
오디오는 지원하지 않습니다. OpenCV가 지원하는 코덱의 MP4를 사용하세요.
원본 시간축과 OpenCV 프레임 수가 다르면 잘못된 프레임 연결을 피하기 위해 수치 분석을 보류합니다.

## 관절 측정·그래프·CSV (3단계)

1. AI 분석 후 선수를 선택합니다. 기존 랜드마크 캐시에서만 각도를 계산하므로
   측정을 위해 MediaPipe를 재실행하지 않습니다.
2. 상단 **관절 측정·그래프 패널**을 켭니다. QSplitter 경계로 영상/표/그래프 크기를 조절하거나
   패널을 접어 기존 영상 크기로 볼 수 있습니다. 초기에는 기존 화면을 위해 접혀 있습니다.
3. 표에는 현재 프레임의 원시값과 선택 구간의 원시 최소/최대/변화폭/항목별 유효 수를 표시합니다.
   통계 값은 유효 표본이 2개 이상일 때 표시합니다. 부족하면 `측정 불가`이며 0으로 대체하지 않습니다.
4. **관절 각도 표시 ON/OFF**는 선택 선수의 팔꿈치/무릎/어깨 근처에 유효한 값만 표시합니다.
   기존 골격 토글과 독립적으로 작동합니다.
5. 그래프에서 좌우 팔꿈치/무릎/어깨와 몸통 기울기를 개별 선택합니다.
   X축은 실제 PTS 초, Y축은 각도입니다. 마우스로 확대/축소/이동하고 **그래프 초기화**로 복원합니다.
   클릭하면 가장 가까운 영상 프레임으로 이동하며 재생 중에는 현재 위치선만 움직입니다.
6. **구간 시작 A**, **구간 종료 B**는 현재 프레임을 지정합니다. 두 프레임 모두 포함합니다.
   구간 길이는 B 프레임의 표시가 끝나는 시각까지입니다. A만 지정하면 영상 끝까지,
   B만 지정하면 영상 시작부터 적용합니다. **구간 초기화**로 전체 추적 범위 통계로 돌아갑니다.
   구간은 선수 재선택과 독립적이며 영상을 다시 열면 초기화합니다.
7. **표시용 3프레임 평활화**는 그래프/각도 오버레이에만 적용합니다. 원시 값은 변경하지 않습니다.
   결측/신원 구간을 넘지 않으며 결측 프레임을 채우지 않습니다.
8. **CSV 내보내기**로 현재 통계 범위의 프레임을 UTF-8 BOM CSV에 저장합니다.
   영상 경로/크기/mtime, 원본 시간/PTS 출처, 프레임 번호, 선택 세션/추적 구간,
   추적 중단 원인, 항목별 원시값/표시 평활화값/유효 여부/불가 사유를 포함합니다.
   무효 값은 빈 칸이며 표에 표시한 반올림 전의 원시값을 저장합니다.

측정 항목과 의미:

| 항목 | 계산/단위 |
|---|---|
| 좌우 팔꿈치 | 어깨–팔꿈치–손목의 내각, 편 상태 약 180도 |
| 좌우 어깨 | 팔꿈치–어깨–골반의 화면 평면 내각, 실제 어깨 회전각 아님 |
| 좌우 무릎 | 골반–무릎–발목의 내각, 편 상태 약 180도 |
| 몸통 기울기 | 양어깨/골반 중심을 잇는 선과 화면 위쪽 수직축의 각도, 실제 전후 굴곡 아님 |
| 좌우 손목 상대 높이 | (같은 쪽 어깨 Y − 손목 Y) / 몸통 길이, 어깨보다 위가 양수 |

각도는 0–180도이며 원본 영상의 가로/세로 픽셀 축척을 적용합니다. 제로/미소 벡터,
저신뢰도/화면 밖 관절 및 신원 확인이 안 되는 프레임에는 수치를 만들지 않습니다.
월드 좌표는 이 단계의 측정에 사용하지 않습니다.

`AnalysisCache.measurements`는 `FrameMeasurement`를 프레임 번호별로 보관합니다.
각 항목의 `MetricValue.raw`, `display`, `valid`, `reason`을 분리합니다.
선택 세션 ID는 영구 신원 ID가 아니며 재선택하면 이전 선택의 수치를 지우고 새로 계산합니다.
누락/후보 혼동/이동 기준 초과로 추적을 중단하면 이후 자동 연결하지 않습니다.
현재 프레임의 최초 중단 원인과 프레임 번호, 전체 선택의 측정 가능 수를 상태줄에 표시합니다.
분석 가능 프레임 비율은 지정 범위에서 9개 항목 중 하나 이상 유효한 프레임 기준이며,
항목별 신뢰도는 표의 유효 수를 함께 확인하세요.

## 스윙 후보·동작 단계 분석 (4단계)

1. AI 자세 분석 → 선수 선택 → 관절 측정 완료 후 **라켓 손**을 오른손/왼손으로 지정합니다.
   **스윙 자동 검출**은 현재 관절·측정 캐시만 사용하며 MediaPipe를 다시 실행하지 않습니다.
2. A/B가 없으면 전체 영상, 있으면 지정 범위를 분석합니다. **검출 설정**에서 민감도,
   최소 지속 시간, 병합 간격, 최대 시간 간격, 분석용 median 평활화/윈도를 조절합니다.
   기존 표시용 3프레임 평활화와 별개입니다. 백그라운드 진행률/취소를 지원합니다.
3. 접이식 **스윙 목록·타임라인** 패널에서 이벤트를 선택하면 시작 프레임으로 이동하고
   그래프가 해당 구간을 보여줍니다. 기존 A/B 통계는 유지되며 **선택 → A/B**를 눌러야 변경됩니다.
   목록과 상세 분석/타임라인을 탭으로 전환하고 분할선을 끌어 영상 영역을 조절할 수 있습니다.
4. **동작 단계 표시**는 선택 이벤트의 그래프 단계 영역·경계와 현재 단계 표시를 제어합니다.
   타임라인의 시간축은 기존 그래프와 연결되며 클릭 탐색, 확대/축소, 초기화를 지원합니다.
   **선택 스윙 재생**, **스윙 구간 반복**으로 경계를 검토합니다.
5. **자동 분류 결과 수정/추가/삭제**에서 시작·끝 프레임, 후보 종류, 사용자 라벨,
   단계별 경계를 편집합니다. 적용 전까지 원본은 바뀌지 않으며 취소할 수 있습니다.
   단계 역순·겹침·범위 초과는 거부하고 미지정 부분은 UNKNOWN_PHASE로 남깁니다.
6. **자동 결과로 복원**은 현재 문서를 자동 분석 원본으로 되돌립니다.
   수동 변경이 있는 문서를 재분석/교체할 때 확인합니다. 영상·선수 선택 문맥별 결과를
   `output/motion_events/<영상 식별자>.json`에 자동 저장하며 저장/불러오기 버튼도 제공합니다.
   자동 원본, 현재 수정본, 수정 작업과 이전 저장 이력을 분리하고 임시 파일을 거쳐 저장합니다.
7. 저장 결과를 불러오면 과거 분석 스냅샷으로 표시합니다. 현재 측정 캐시와 자동 혼합하지 않습니다.
   영상 경로·크기·mtime, 선택 기준 프레임/몸통 위치, 라켓 손, 알고리즘 버전으로 문맥을 구분합니다.
   선수 ID는 영구 신원이 아닙니다. 영상을 옮기거나 바꾸면 다른 영상으로 취급합니다.

손목 좌표는 어깨 중심에 대한 상대 위치를 몸통 길이로 정규화합니다. 실제 PTS로 속도와
각속도를 계산하며 결측·신원 변화·비정상 PTS·큰 시간 간격을 넘어서 연결하지 않습니다.
적응형 속도 기준, 이동량, 지속 시간, 관절 변화 및 국소 피크로 후보를 검출합니다.
오버헤드 근거가 있는 후보만 관측된 변화에 따라 READY/BACKSWING/FORWARD_SWING/
FOLLOW_THROUGH/RECOVERY를 분류하고 불충분한 부분은 UNKNOWN_PHASE로 보류합니다.
NO_SWING은 유효 관측에서 후보가 없는 구간이며, 관측 불가 UNKNOWN과 다릅니다.

손목 속도·이동량은 영상 평면의 몸통 길이 단위 상대값이며 실제 라켓 속도가 아닙니다.
움직임 강도는 규칙용 지표이며 물리적 에너지가 아닙니다. 속도 피크를 타격 순간으로 판단하지
않고, 스매시/클리어/드롭 또는 포핸드/백핸드를 확정하지 않습니다. 실제 경기 정확도는 미검증입니다.
설계·판단 기준·검증 결과는 [4단계 검증 기록](docs/stage4_validation.md)을 확인하세요.

## 근거 기반 AI 코칭 관찰 (5단계)

1. 기존 관절 분석·선수 선택·스윙 검출을 완료하고 스윙 목록에서 이벤트를 선택합니다.
   **AI 코칭 분석** 또는 접이식 **AI 코칭 패널**의 **선택 스윙 코칭/전체 스윙 코칭**을 누릅니다.
   기존 캐시만 사용하며 포즈 추론·LLM API·유료 서비스는 호출하지 않습니다.
2. **분석 상태 → 주요 관찰 → 코칭 검토 포인트 → 연습 및 촬영 제안** 순서로 읽습니다.
   기본 목록은 실제 관찰/품질 안내를 최대 3개만 표시합니다. **나머지 펼치기**로
   미관측 단계의 보류 사유까지 확인하고 **단계별 측정 근거** 탭에서 실제 수치·단위를 봅니다.
3. 자동 단계는 후보입니다. 경계/단계를 영상을 보고 확인했을 때만
   **현재 스윙·단계를 직접 확인함**을 켠 뒤 재분석하세요. 사용자 확인은 기술 정확성 검증이 아닙니다.
   확인 전, 단계 불명, 추적/시간 단절, 관절 부족 또는 규칙 적용 불가 시 평가를 보류합니다.
4. 결과를 클릭하면 근거 프레임과 그래프·타임라인 강조로 이동합니다.
   **근거 영상 보기**와 **근거 구간 반복 재생**으로 검토합니다. 기존 A/B 통계는 바뀌지 않습니다.
   영상/측정/스윙 패널은 각각 접을 수 있고 분할선을 끌어 읽기 편한 크기로 조절할 수 있습니다.
5. **확인·보류·오류·메모**에서 사용자 검토 상태, 오류 이유, 메모와 숨김을 적용/취소합니다.
   **숨긴 결과 보기**에서 다시 열고 숨김을 해제할 수 있습니다. 자동 모델 학습은 수행하지 않습니다.
6. 반복 비교는 **전체 스윙 코칭**을 사용합니다. 각 스윙·단계를 확인한 뒤
   **동일 고정 촬영·동일 기술 확인**과 비교 기술 그룹을 입력해야 합니다.
   같은 영상·선수·추적 구간·라켓 손·후보 종류의 관측 차이만 비교하며 유사도/우수도 점수는 없습니다.
7. 선수·손·이벤트 경계/단계·관절 데이터·규칙 설정이 바뀌면 재계산이 필요합니다.
   이전 메모와 검토 상태는 보존하지만 근거가 바뀐 검토는 재확인을 요청합니다.
   저장 결과는 재계산 전까지 과거 결과로 표시하며 현재 영상 탐색에 연결하지 않습니다.
8. 결과와 검토 이력은 `output/coaching/<영상 식별자>.json`에 자동 저장합니다.
   **코칭 결과 저장**은 JSON/UTF-8 BOM CSV 내보내기입니다. 초기화 전 결과와 메모는 이력에 보존합니다.
   기존 `output/motion_events`의 4단계 JSON 형식은 변경하지 않았습니다.

규칙은 [config/coach_rules.json](config/coach_rules.json)에서 관리합니다.
규칙 설정 불러오기와 변경 감지를 지원하며 잘못된 설정은 코칭을 중단하고 플레이어는 유지합니다.
V1 규칙은 백스윙 팔꿈치, 전방 신전, 손목·팔꿈치 피크 관계, 팔로스루, 몸통 변화,
동일 조건 반복 차이, 품질/보류 안내입니다. 검증된 기술 정답 기준이 없어 데이터가 충분하고
사용자 확인을 거쳐도 **측정 관찰만 가능**으로 표시합니다. 실제 경기 기술 평가 정확도는 미검증입니다.
상세 조건과 테스트 결과는 [5단계 검증 기록](docs/stage5_validation.md)을 확인하세요.

## 로그 및 설정

- `logs/app.log`: 실행, 열기, 재생, 탐색, 종료 및 오류 추적을 누적 기록합니다.
- `output/settings.ini`: 창 크기/위치/상태, 골격/각도 표시, 측정 패널/분할 위치,
  그래프 항목/평활화 및 마지막 파일 선택 폴더를 저장합니다.
- 기본 창 크기: 1100×760, 최소 크기: 640×420.
- 스윙 검출 설정, 라켓 손, 단계/패널 표시와 분할 위치도 기존 설정 파일에 저장합니다.
- 스윙 분석 로그에는 대상/제외 사유 요약, 후보·분류·보류 수, 수동 변경, 소요 시간과 오류를 기록합니다.
- 코칭 엔진/규칙 버전, 품질·규칙별 적용/보류, 캐시 재사용, 메시지 수, 사용자 검토 변경과 오류를 요약 기록합니다.
- 코칭 패널 표시/분할 위치/규칙 파일 경로를 기존 설정에 추가 저장합니다.
- 마지막 영상을 자동으로 열거나 재생하지 않습니다.

## 테스트

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

테스트는 임시 MP4와 오프스크린 Qt를 사용하여 실제 디코딩, 재생/일시정지,
프레임 탐색/경계, 파일 오류 후 복구, 설정 복원을 확인합니다. AI 자동 테스트는
합성 관절 및 가짜 검출기를 사용해 신뢰도 필터, 신원 연결 중단, 분석 취소/오류,
UI 응답, 캐시 동기화와 오버레이 좌표를 검증합니다.
3단계 검증은 180도/90도 기준, 좌우/원본 축척, 결측, 선택 세션 격리, 통계/CSV,
합성 VFR MP4의 실제 PTS와 프레임 이미지 및 그래프 마우스 탐색을 포함합니다.

실제 모델/MP4 전체 분석 및 Windows GUI 통합 검증:

```powershell
.\.venv\Scripts\python.exe tests/run_pose_smoke.py --video data/videos/20260707_154513.mp4
.\.venv\Scripts\python.exe tests/run_pose_smoke.py --measurements --video data/videos/20260707_154513.mp4
.\.venv\Scripts\python.exe tests/run_pose_smoke.py --motion --hand right --video data/videos/20260707_154513.mp4
.\.venv\Scripts\python.exe tests/run_pose_smoke.py --coach --video data/videos/20260707_154513.mp4
```

영상 경로를 생략하면 `data/videos`의 첫 MP4를 사용합니다. `--offscreen`으로
디스플레이 없이도 실행할 수 있습니다. 검증 후 자동 종료하며 JSON 결과와
골격 ON/OFF 화면을 `output/pose_smoke_*`에 저장합니다.
`--measurements`는 각도/그래프/A/B/CSV까지 검증하고 `output/measurements_smoke_*` 및
`output/measurements_smoke.csv`에 산출물을 저장합니다.
`--motion`은 기존 검증에 스윙 검출/타임라인/수동 수정/JSON 재로딩을 추가합니다.
결과와 화면은 `output/motion_smoke_*`, 테스트 수정본은 별도 `output/motion_smoke_events`에
저장하여 사용자의 실제 수동 보정 파일을 덮어쓰지 않습니다.
`--coach`는 기존 전체 검증에 품질 보류/코칭 근거 목록 선택/그래프 연결/검토 메모 재로딩/
JSON·CSV를 추가합니다. `output/coach_smoke_*`에 결과를 기록하고 별도
`output/coach_smoke_events`에 저장합니다. 실제 기술 지도 정확도를 검증하는 테스트는 아닙니다.

실제 영상의 모든 프레임에 대한 관절 정답 대조 및 신원 정확도 수치 평가는 수행하지 않습니다.
일반적인 가림/유사 복장/교차 상황에서 잘못 연결될 가능성을 완전히 제거하지 못합니다.
관절 위치의 연속성 검사는 보수적으로 연결을 중단하며 영구 신원 보장을 제공하지 않습니다.
거리/운동/가림에 따른 미검출과 표시 제한은 모델 및 촬영 조건의 제약입니다.
상세 검증 결과는 [2단계 검증 기록](docs/stage2_validation.md)을 확인하세요.
추가 측정·시간축 검증과 한계는 [3단계 검증 기록](docs/stage3_validation.md)을 확인하세요.
